How the Algorithm Works

Design and Analysis of Algorithms • Divide and Conquer + Greedy Strategy

1

Divide & Conquer: Merge Sort

The input train list is recursively halved into subproblems, sorted at the base case, and merged in ascending order of arrival time: O(n log n) in all cases. Ties are broken by departure time.

2

Greedy Platform Reuse

For each incoming train, scan active platforms in order. Reuse the first platform whose last departure is ≤ this train's arrival (last_departure ≤ arrival). If no platform is free, open a new platform: O(n × p).

3

Optimal Platform Count

Total platforms opened equals the exact minimum needed. This is mathematically equal to the maximum number of simultaneous overlapping trains at any point in time, verified via the Two-Pointer peak scan.
